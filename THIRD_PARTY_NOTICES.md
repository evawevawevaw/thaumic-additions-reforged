# Происхождение ресурсов

Новый код порта лицензирован по MIT (см. LICENSE).

Текстуры в `src/main/resources/assets/thaumicadditions` взяты из
Thaumic Additions 0.41, автор Zeith, по указанию владельца проекта.
Для текстур жезлов источником служит каталог `assets/thaumcraft/textures/models`
оригинального jar; в порте они размещены в собственном namespace.
PNG скопированы без изменения содержимого, имена и пути адаптированы.
Текстуры надетой брони взяты из `textures/models/adaminite_1.png` и
`adaminite_2.png`; кадры активной брони — из `adaminite_1/1.png`–`4.png` и
`adaminite_2/1.png`–`4.png`. Иконки предметов сохраняют исходные метаданные анимации.
Истощённый осколок использует текстуру из зависимости Thaumcraft, как в
оригинальном моде; отдельный PNG не копировался.
Звуки перенесены из исходного каталога sounds с нормализацией регистра имён.
Геометрия старого тигля адаптирована из Techne-ресурса OldCrucible.tcn;
геометрия трубы восстановлена по числовым параметрам старой модели.
Конденсатор, кристаллизатор, генераторы и семь улучшений используют оригинальные
PNG GUI/блоков/предметов/моделей. Кубоиды тёмного/обычного генераторов восстановлены
по числовым параметрам старых моделей. Кристаллы используют текстуру и геометрический
API зависимости Thaumcraft. Отсутствующий speed_condenser.png не заменялся выдуманным
исходным ресурсом. Анимации pure_warp still/flowing и иконка ведра скопированы из исходных
textures/blocks/fluids и textures/items вместе с mcmeta. Старый Java-код
в новый проект не включён.

зависимости; LICENSE этого проекта не меняет их лицензии.
